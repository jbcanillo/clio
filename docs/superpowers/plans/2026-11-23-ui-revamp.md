# Clio UI/UX Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle Clio to the Symbiosis mockups (teal + orange), with four tabs (Chat, Diary, Reminders, Notes), where CopilotKit generative UI is the core interaction and every tab has its own chat thread.

**Architecture:** One `CopilotKit` provider per scope (`chat|diary|reminders|notes`), each with its own `threadId`, mounted once in the app shell so histories survive tab switches. A headless `ClioChat` (built on `useCopilotChat`) renders messages and interactive generative cards; the same card components are used by the tab screens. Per-scope action subsets and context are registered by `ClioActions`. Two small backend endpoints (notes list + checklist toggle, daily range) feed the Notes and Diary tabs.

**Tech Stack:** React 18, Vite, Vitest + Testing Library, Tailwind 3 + daisyUI 5, `@copilotkit/react-core` / `react-ui` 1.90.0 (exact pin), Express 4 + Vitest + supertest (backend), recharts, lucide-react.

**Spec:** `docs/superpowers/specs/2026-11-23-ui-revamp-design.md` (mockups and tokens in `docs/ui/`, especially `docs/ui/symbiosis_ai/DESIGN.md`).

## Global Constraints

- Work on branch `ui-revamp` (created in Task 1). Commit after every task; each commit message ends with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Keep `@copilotkit/*` pinned to exactly `1.90.0`. No new CopilotKit packages.
- **No speech-to-text or voice anywhere**: no mic buttons, no voice-memo/waveform cards. No photos, book covers, calendar sync, "multi-agent sync" or avatar photos.
- Colors (exact): teal `#0D4C55` / `#146B78` / `#072B30`; orange `#FF6B35` / `#FA824C` / `#FFE8DF` / tint `#FFF8F5`; canvas `#F8FAFA`, card `#FFFFFF`, inset `#EDF2F2`, border `#E1EAEB`; text `#131E22` / `#47585F` / `#82949B`. Orange is only for AI/action elements and urgency; teal for structure. No purple, no "galaxy" styling.
- Fonts: Plus Jakarta Sans (headings, labels) + Inter (body). Radii: cards `rounded-lg`/`rounded-xl`, chips/buttons `rounded-full`. Elevation per `DESIGN.md` levels 0-3.
- Four tabs, routes `/chat` (default), `/diary`, `/reminders`, `/notes`; Settings at `/settings`, backup at `/backup` and `/restore` (HashRouter).
- Security rule: note/diary text never flows back to the model through a tool result. "show_*" actions return a fixed sentence and cards fetch their own data. The model can't delete/overwrite; destructive actions stay behind approval cards.
- Existing tests keep passing or are updated/deleted together with the code they cover. Run `npm test` and `npm run typecheck` in `frontend/`, and `npm test` in `backend/`, at the end of every task that touches that package.
- Rendered chat/note text is always React text, never `dangerouslySetInnerHTML`.

## Review Focus

1. A checklist item is ticked while the note changed elsewhere (409): the card must refetch and show a "note changed, reloaded" message, never overwrite.
2. Reminder complete/snooze/accept-reschedule fails (network or 4xx): the card reverts its optimistic state and shows an inline error.
3. Clio unreachable or not configured (`/api/copilotkit` 503 / offline): the chat shows an inline retryable error and the composer stays usable; tabs still show their own data.
4. Empty and loading states: no reminders / notes / diary entries, timezone not yet loaded, 100+ items: friendly empty card, no crash, no layout break.
5. Hostile text: note titles, reminder titles and chat messages containing `<script>`/HTML/markdown render as plain text.
